WHAT THIS IS
------------
First JEPA-based self-supervised speech model for Kazakh language.
Adaptation of Audio-JEPA (Tuncay et al., ICME 2025) to KSC2 dataset.
Target: arxiv preprint within ~6 weeks.

GITHUB REPO
-----------
https://github.com/aiken-kazin/Kaz-JEPA
(fork of LudovicTuncay/Audio-JEPA)

WORKFLOW
--------
1. Develop on MacBook (no GPU, for testing)
2. Push to GitHub
3. Pull on training machine (RunPod or university WSL2)
4. Run training on RTX 5090

KEY CONSTRAINTS
---------------
- Do NOT modify original Audio-JEPA source files
- Only ADD new files: convert_to_hdf5.py + configs/data/ksc2.yaml
- ONE allowed source modification: vision_transformer.py import shim
  (flash_attn fallback to nn.MultiheadAttention when CUDA missing)

ENVIRONMENT-SPECIFIC GOTCHAS
----------------------------
On Mac (CPU, testing):
  uv sync --no-install-package flash-attn
  PROJECT_ROOT=$PWD uv run --no-sync python src/train.py ...

On RunPod / WSL2 with RTX 5090:
  - Install PyTorch with CUDA 12.8 for Blackwell sm_120 support:
    pip install --upgrade torch torchvision torchaudio \
      --index-url https://download.pytorch.org/whl/cu128
  - flash-attn skip OK, we have a shim
  - Always pass test=False (JEPAModule has no test_step → crashes)
  - PROJECT_ROOT=$PWD env var is required (referenced in
    configs/paths/default.yaml)
  - Paste commands as ONE line (terminal breaks them silently)

COMMANDS REFERENCE
------------------
Convert data (one-time per dataset):
  PROJECT_ROOT=$PWD python convert_to_hdf5.py \
      --src /path/to/ISSAI_KSC2 --out data/KSC2

GPU sanity check (100 steps):
  PROJECT_ROOT=$PWD python src/train.py data=ksc2 trainer=gpu \
      trainer.max_steps=100 data.batch_size=32 data.num_workers=4 \
      tags='[smoke]' test=False

Full pretrain (30k steps ~ 1 hour on 5090; 100k ~ 3.5 hours):
  PROJECT_ROOT=$PWD nohup python src/train.py data=ksc2 trainer=gpu \
      trainer.max_steps=30000 data.batch_size=32 data.num_workers=8 \
      tags='[full,kazakh,jepa]' test=False > training.log 2>&1 &

Resume from checkpoint:
  ...same command... \
      ckpt_path=logs/train/runs/<date>/checkpoints/last.ckpt

Monitor:
  ps -p <PID>                                  # alive?
  nvidia-smi                                   # GPU usage
  tail -50 training.log                        # recent log
  ls -lh logs/train/runs/*/checkpoints/        # checkpoints

KEY METRICS TO WATCH
--------------------
- val/loss → should decrease smoothly. Plateau means hit
  current config's limit.
- val/variance → should stay > 0.1 (or much higher with our
  scaling; our 30k run gave 22.38).
  Near zero (< 0.001) means COLLAPSE → model useless.

DECISIONS LOGGED
----------------
- Stick with Audio-JEPA fork, do NOT rewrite from scratch.
  Reason: minimal-change adaptation is academic norm; rewriting
  costs months without scientific benefit.
- KRSL (Kazakh Sign Language) V-JEPA 2 idea: parked as potential
  Project 2 after Kaz-JEPA preprint, contingent on dataset
  availability (need to verify with ISSAI / KazNU).
- ASR chosen as downstream task (vs simpler Speaker/Language ID).
  Reason: most publishable for speech preprint; KSC2 already has
  transcripts so no extra data collection needed.
